# Стили SPA

Макет страницы: два блока — граф и информационная панель.

## Layout

- Контейнер графа: 80% ширины, слева
- Панель информации: 20% ширины, справа
- Граф занимает всю высоту viewport
- Панель имеет скролл при переполнении

## Цветовая схема

- Узлы: скруглённые прямоугольники с именем cell
- Рёбра: направленные стрелки
- Подсветка: жёлтый цвет для выбранного узла, серый для остальных
