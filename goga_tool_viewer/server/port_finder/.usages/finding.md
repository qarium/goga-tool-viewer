# Поиск свободного порта

Для потребителей port_finder — как получить свободный порт.

## Использование

Вызвать `find_free_port(min_port, max_port)` для получения номера свободного порта.
Рекомендуемый диапазон: 49152–65535 (ephemeral ports).

Функция выбирает случайный порт из диапазона и проверяет его доступность через socket.
Если порт занят — пробует следующий случайный.
