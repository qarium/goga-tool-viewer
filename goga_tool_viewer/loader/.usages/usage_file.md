# Загрузка usage-файлов

Для потребителей loader — как загрузить содержимое usage .md файлов.

## Использование

Вызвать `load_usage_file(usage_path, project_root="")` — вернёт содержимое .md файла как строку.
usage_path — относительный путь к .md файлу от корня проекта
(например ".goga/usages/conventions.md" или "goga_tool_viewer/parser/.usages/loading.md").
project_root — абсолютный путь к корню проекта. Если пустой — используется текущая рабочая директория.

## Защита от path traversal

Двухуровневая проверка: строковая (запрет ".." и "/") и resolve-based (проверка что путь не выходит за корень проекта).
Дополнительно проверяется расширение файла — только .md.

## Исключения

- `ValueError` — путь содержит "..", начинается с "/", выходит за пределы проекта или не имеет расширение .md.
- `FileNotFoundError` — файл не найден по указанному пути.
